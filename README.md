# Bata Maru ri · बातां मरु री

A digital space for Rajasthani folklore, local story summaries, and academic Rajasthani studies.

## Adding a New Story

1. Create a new Markdown file in `docs/posts/` named `YYYY-MM-DD-short-title.md`.
2. Copy the frontmatter from `docs/posts/2026-11-16-story-template.md`.
3. Commit and push to `main` — GitHub Actions will automatically rebuild and publish the site.
